App overview

Dominant role

Dominant — creates and manages tasks

The Dom sets up a sub profile with their name and preferred play types, then generates a personalised weekly task list. Tasks are shared with the sub via QR code.

Submissive role

Submissive — receives and completes tasks

The Sub scans the QR code from the Dom's phone to receive their weekly tasks. They check off tasks, log water intake, track fitness, and access safety resources.

Step by step

1

Dom — set up a sub profile

Go to Settings → + Add Profile → enter the sub's name → tap the tune icon to select play types → tap Save.

2

Dom — generate weekly tasks

Go to Tasks tab → tap the refresh icon (top right) → review the safety reminder → tap Confirm & Generate.

3

Dom — share via QR code

Tap Show QR — Share with Sub. A QR code appears on screen. Show it to the sub.

4

Sub — scan the QR code

Open the app → Tasks tab → tap the QR scan icon (top right) → point camera at the Dom's screen. Tasks import instantly.

5

Sub — complete tasks

Tap any task to expand it and read the details. Tap the checkbox to mark it done. Track water and weight from the Home tab.

Tip: You can use the app on a single device by switching roles in Settings.

What to test

1

Installation

Did the app install without issues? Did it open correctly on first launch?

2

Task generation

Set up a profile, generate tasks, and check if the tasks make sense for the play types selected.

3

QR code transfer

If you have two devices (or can test with another person), try the full QR scan flow. Did the tasks transfer correctly?

4

General feel

Is anything confusing? Are there features missing that you'd expect? Does anything crash or behave unexpectedly?
